> *Developed for HackCelestial 4.0 under the B.L.A.S.T. Protocol*

---

## 🌟 1. The Problem & Vision

### The Problem
During mega-events (Olympics, World Cups, cultural festivals), venue managers, transit authorities, and hospitality operators operate in **silos**. Nobody has a unified operational picture. As a result:
- Concourse turnstiles and metro stations breach dangerous crowd densities.
- Neighboring fan festival parks and dining promenades sit with under-utilized capacity.
- Attendees have zero visibility into transit gridlocks and make uninformed arrival choices.

### The Solution: CrowdPulse
CrowdPulse bridges these silos by maintaining **one real-time shared operational picture**:
1. **Predicts** crowd pressure and transit bottlenecks 30–60 minutes in advance via Holt-Winters time-series modeling and event schedule weighting.
2. **Reallocates** capacity deterministically using an in-house Linear Programming (LP) Simplex Solver to divert shuttle fleets and stagger ingress.
3. **Guides** both stakeholders through dedicated interfaces:
   - **`/organizer` Command Console:** Heatmaps, breach alert feed, and interactive what-if sliders.
   - **`/visitor` Companion App:** "Skip the Queues" alternate zone recommendations, optimal travel windows, and crowd-aware routing.

```
|  • forecasting.service.js: Holt-Winters Smoothing + Event Ingress Surge |

|  • alert.service.js: Threshold Boundary Evaluator & Early Warnings      |
+------------------------------------+------------------------------------+
                                     ▲
                            (In-Memory Sync)
                                     ▼
+-------------------------------------------------------------------------+
|                           DATA & SIMULATION LAYER                       |
|  • In-Memory Live Engine (crowdSimulator.js): Virtual 5-min tick clock  |
|  • Persistent Store: MongoDB (Zone, Venue, TransitEdge, Snapshots)      |
|  • Free External Services: OpenStreetMap Tiles, OSRM Public Routing     |

```

### Why Judges Value This Implementation
- **100% Deterministic & Explainable:** Decisions are generated by linear programming and time-series mathematics, not an LLM hallucinating crowd numbers.
- **Zero API Cost / Free-Tier Only:** Uses OpenStreetMap, Leaflet.js, and OSRM public servers. No paid keys or rate-limited external tokens.
- **Fail-Safe & Resilient:** If network or database writes hiccup, the in-memory cache and WebSocket ticker continue running smoothly.

## 🚀 3. Quick Start & Execution

### Prerequisites
- Node.js (v18+)
- MongoDB (Running locally on default port `27017` or configured via `MONGODB_URI` in `.env`)

### Install Dependencies
```bash
# Install root, backend and frontend dependencies
npm --prefix server install
npm --prefix client install
```

### Run Comprehensive Automated Verification
```bash
npm test
```
*Verifies database connectivity, the LP solver, OSM tile reachability, OSRM routing, pure service unit tests, and end-to-end integration APIs.*

### Start Local Development Servers
In two separate terminal tabs:

**Tab 1: Backend Server & Live Simulator**
```bash
npm run dev:server
```
*Runs at `http://localhost:5000` with WebSocket broadcasting on `ws://localhost:5000`.*

**Tab 2: Frontend Web Application**
```bash
npm run dev:client
```
*Runs at `http://localhost:5173`.*

## 🎬 4. Hackathon Judging Demo Script (3-Minute Walkthrough)

1. **Open the Application (`http://localhost:5173/#/organizer`)**:
   - Point out the **Live Heartbeat Pill** and the ticking virtual event clock.
   - Show the **Leaflet Geospatial Perimeter Map**:
     - *Grand Olympic Arena Zone* (Amber / Elevated)
     - *Central Transit Hub* (Orange / Warning)
     - *Festival Fan Park* & *Promenade* (Green / Normal)
     - Transit lines connecting zones with real-time throughput.

2. **Show the LP Redistribution Solver**:
   - Highlight the action card: `Deploy +7 Express Shuttles on Electric Shuttle Alpha`.
   - Explain: *"Our system solved an integer linear program in 10ms to divert idle shuttles from the transit hub towards the under-utilized Fan Park, providing an estimated 24.5% crowd relief."*

3. **Demonstrate the "What-If" Scenario Sliders**:
   - Scroll to the bottom drawer.
   - Drag the **Demand Multiplier** slider from `1.0x` to `2.2x` (simulating an unexpected crowd surge).
   - Watch the map and metrics instantly update: zones turn red (Critical), and new emergency turnstile throttling alerts appear in the live feed.
   - Click **Reset** to restore baseline.

4. **Switch to the Visitor Companion (`http://localhost:5173/#/visitor`)**:
   - Click the **"Visitor Companion"** switcher in the top navbar.
   - Show the **Recommended Travel Window** (`Immediate — Next 40 Mins`).
   - Show **"Skip the Queues"**: Notice how *Festival Fan Park* is highlighted with open dining and zero lines.
   - Test the **Live Route Planner**: Select *Central Transit Hub* $\rightarrow$ *Grand Olympic Arena*. The app flags high transit congestion and proactively recommends routing to the Fan Park live megascreen to save 15 minutes.
